# いけめんだいすき

友だち同士で「顔が好きな9人」を決める静的Webサイトです。

## 現在の構成

- STARTO・グループ所属ジュニア：元サイトの公開 `members.json` をブラウザから読み込み（137人想定）
- 高校生以上の無所ジュニア：56人（東京40・関西16）
- 俳優：100人
- 合計：293人想定

サイト本体の選考ロジックは新規実装です。元サイトのJavaScript/CSSはコピーしていません。

## 写真

追加156人はすべて写真参照設定済みです。

- 無所ジュニア56人：STARTO ジュニア公式サイトの各プロフィール画像への外部参照
- 俳優100人：WEBザテレビジョンの各人物プロフィール画像への外部参照
- 元137人：元データに設定されている画像参照を利用

画像ファイル自体はこのZIPには再配布・同梱していません。サイトを開いたときに公開元から読み込みます。公開元のURL変更・画像削除・外部参照制限などにより、将来表示されなくなる場合があります。

`data/photo-checklist.csv` に追加156人の画像URL・出典ページ・ローカル差し替え用ファイル名を記録しています。

外部画像が表示されない人だけ、JPEG画像を以下に置けばフォールバックとして使えます。

`assets/photos/<ID>.jpg`

`extra-members.json` の `localPhoto` を指定すると、その画像を最優先にできます。

## 遊び方

1. 予選：1画面最大8人、好きな顔を最大3人選ぶ
2. 本選：候補が18人を超える場合、4〜6人程度の均等な組を3ROUND比較して各画面1位・2位を選ぶ
3. 決勝：18人から二択比較でTOP9を確定
4. 途中経過はブラウザの `localStorage` に保存

## 公開方法

GitHub Pagesなら、このフォルダの中身をリポジトリ直下に置いて Pages を有効にすれば動きます。ローカルで確認する場合も `file://` 直開きではなく簡易Webサーバー経由で開いてください。

### 友だちだけで使う場合

`<meta name="robots" content="noindex,nofollow,noarchive,nosnippet">` は設定済みです。ただし GitHub Pages は通常「完全な非公開」ではなく、URLを知っている人はアクセスできます。完全にアクセス制限したい場合は認証付きホスティングが必要です。

## 元STARTOデータが読み込めない場合

`app.js` 内の `ORIGINAL_DATA_URL` は元サイト公開データを参照しています。元URLが変更された場合は参照先を更新してください。
